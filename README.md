# 像素坦克：废土突围

HTML5 Canvas 坦克游戏。当前阶段加入开始菜单、局外永久成长（localStorage 存档）、完整结算统计与打磨优化；保留此前全部内容（肉鸽升级、Boss 战、区域推进、像素特效与音效）。

## 运行

**最省事（无需安装任何东西）：**

直接双击 `offline/index.html` 即可在本地浏览器游玩（单文件、离线、手机/PC 通用）。

## 在线试玩

已部署上线（GitHub Pages），点击或扫码即可直接游玩：

- https://wen-6-dao.github.io/pixel-tank-wasteland/

开始菜单内置二维码，手机扫码即可打开。

**开发模式：**

```bash
npm start
```

或直接 `node server.mjs`，然后浏览器打开 http://localhost:5173 。

> ES Modules 需要 HTTP 协议加载，不能直接双击 `index.html`（file:// 会被浏览器拦截模块请求）。
> 如果重新改了源码，运行 `node scripts/build-offline.mjs` 重新生成离线版。

## 手机端与扫码

- 手机浏览器打开游戏地址即可玩：触屏设备自动显示左侧虚拟摇杆（移动）与右侧开火按钮，炮塔自动瞄准最近敌人。
- 开始菜单内置二维码：本地开发时显示局域网地址（同一 WiFi 手机扫码即玩），部署到 GitHub Pages / Netlify 后自动显示线上地址。
- 建议横屏体验（竖屏也有提示，仍可游玩）。

## 部署到 Netlify（所有人都能玩）

1. 把 `游戏` 文件夹推到 GitHub（或直接拖拽文件夹到 Netlify 控制台）。
2. Netlify 会自动识别静态站点（仓库已含 `netlify.toml`，`publish = "."`，无需构建命令）。
3. 部署完成后访问线上地址，开始菜单的二维码会自动指向该地址，手机扫码即可游玩。

## 开始菜单与局外成长

- 启动进入开始菜单：显示最高分与金币，提供 6 项永久升级（初始伤害 / 初始生命 / 初始射速 / 开局护甲 / 财富加成 / 初始多重），用每局结算的金币购买，开局自动生效。
- 每局结束结算统计：击杀数（含 Boss）、升级数、累计经验、得分、获得金币与最高分；最高分与金币自动写入 localStorage（`tank-battle-save`），刷新页面保留。
- 得分规则：击杀 25 分、Boss 150 分、波次 100 分、区域 50 分、经验 1:1。
- 金币规则：`经验/10 + 区域×5 + Boss×20`，可被"财富加成"永久升级放大。
- 游戏结束可"再来一局"或"返回菜单"；永久升级对每一局生效。

## 特效与音效

- 粒子系统：爆炸火球与烟尘、砖块碎裂碎屑（带重力）、枪口火花、命中火花、燃烧余烬、Boss 出场爆裂。
- 屏幕震动：按事件强度衰减抖动（砖碎轻微、爆炸中等、Boss 出场与死亡剧烈），偏移取整保证像素锐利。
- 冻结帧：命中停顿——爆炸、玩家受击、Boss 死亡时世界短暂暂停，增强打击感；另有爆炸/受击白闪。
- 8-bit 音效（Web Audio 合成，无需音频文件）：射击、爆炸、砖碎、敌人死亡、升级音阶、受击、Boss 出场、拾取。
- 音效控制：主音量 0.45、单音音量 ≤0.26、并发上限 12 音色，快速衰减包络，避免刺耳；按 M 静音。
- 背景音乐：优先加载 `assets/music.ogg`（构建时自动内联进离线版），缺失时回退到内置 8-bit 循环；按 B 或点右上角 ♪ 开关，点 ◐ 打开音量面板（0~100% 滑块），音乐开关与音量独立持久化，且与音效静音互不影响。
- 播放可靠性：每次用户手势都会尝试解锁/恢复 AudioContext，切回前台自动续播，避免“首屏无声、需再点一次”的问题。

## Boss 战（每 5 波）

- Boss 为 2 倍尺寸（26px）的红色重型坦克，血量随区域非线性提升（`120 + 60×(区域-1) + 30×(区域-1)²`）。
- **肉鸽 Buff**：Boss 开局随机抽取 1~3 个增益（铁壁免伤、弹幕强化、嗜血回血、相位无敌、召唤大师、荆棘反弹、极速、狂暴光环、巨人），互斥组合不会同时出现，增益标签显示在血条上方。
- 攻击模式循环：扇形弹幕（5 发）→ 环形弹幕（10 发）→ 召唤小兵（最多 4 个）。
- **护盾**：每损失 25% 生命触发一次护盾（数值随区域增长，3 秒后破裂，6 秒空窗）；燃烧等持续伤害可以穿透护盾。
- **残血暴走**：血量低于 30% 触发 1 秒预警后暴走——攻速 1.0s、子弹伤害 22、冲锋间隔 2.5s、冲锋留下燃烧轨迹，且不再召唤小兵（难度置换）。
- **冲撞眩晕**：冲锋前 0.4 秒白闪预警；命中玩家造成 15 伤害并眩晕 1.2 秒（无法移动/射击）；玩家携带能量护盾（无敌）可免疫眩晕；Boss 冲锋撞墙会自晕 0.6 秒，可被玩家利用。
- 血量低于 50% 进入强化模式：弹幕更多更密、周期性冲锋、额外快速射击。
- 击败后掉落 4 枚以上大型经验宝石与 2 个随机道具，随后三选一升级并进入下一区域（地图重新随机生成，属性与升级保留）。

## 玩法流程

- 波次清空后游戏暂停，弹出三张随机升级卡片（不会重复给出已满级的升级）；击败 Boss 的波次会先结算掉落、再升级、再换图。
- 点击卡片立即生效并叠加；每波结束重复一次。
- 敌方子弹现在会伤害玩家：护甲减免、受击后 0.4 秒无敌闪烁、生命恢复持续回血；生命归零游戏结束，按 R 重新开始。
- 普通坦克血量 2、射手坦克血量 4，配合伤害/暴击/穿透/爆炸升级，属性变化肉眼可见。

## 技术要点

- 升级池独立模块 `world/upgrades.js`：每个升级带 `max` 叠加上限，`apply(player)` 直接改属性；`player.upgrades` 记录层数。
- 子弹携带升级快照（伤害/穿透/爆炸/冰冻/燃烧/暴击），发射时从玩家属性拷贝，命中后逐项结算。
- 波次与升级解耦：`WaveManager` 不再自动开下一波，波次清空后由主循环切换状态机（`playing → upgrading → playing`），三选一期间逻辑更新完全暂停。
- Boss 继承普通敌人实体但重写 `update`：攻击模式用计时器轮换，死亡由主循环统一结算掉落；`clearField` 清屏道具会跳过 Boss。
- 爆炸同时结算范围伤害与砖墙破坏；燃烧为持续伤害，死亡统一由主循环回收并掉落经验。
- 玩家成长软上限：伤害最多 ×4（之后每层 +0.25）、射速下限 0.10s、暴击率上限 80%、爆炸半径上限 120px——防止后期数值爆炸。
- 普通敌人血量随波次曲线增长：`base × (1 + 0.10×(波次-1) + 0.06×(波次-1)^1.5)`，小怪不再是秒杀对象。
- 射击冷却按真实时间计算，浏览器卡顿追帧不会让玩家连发。
- 存档模块 `meta/save.js`：`localStorage` 读写带容错（隐私模式静默失败），永久升级开局通过 `applyMeta` 注入玩家属性。
- 状态机扩展为 `menu → playing → upgrading → playing → gameover`；菜单与结算覆盖层均为 DOM，逻辑更新在非 playing 状态暂停。
- 子弹碰撞改为分段检测（每段 ≤4px），高速子弹不会穿透砖墙/钢墙。
- 随机数种子：`core/rng.js` 实现 mulberry32，地图、波次构成、Boss Buff、出生点统一走种子序列——同一种子整局可复现（HUD 显示种子，R 重开换新种子）。
- 粒子系统使用对象池：粒子死亡后回收复用，避免频繁 GC；碰撞采用先 X 后 Y 的分离轴检测。
- 移动端输入：键盘/鼠标优先，无则读虚拟摇杆与开火按钮；`scripts/build-offline.mjs` 把 ES Modules 依赖内联为 data: URL 模块，生成双击即玩的单文件离线版。
- 二维码：内嵌 `qrcode-generator`（MIT，`src/vendor/qrcode.mjs`），菜单内动态生成分享地址的二维码；本地 localhost 时通过 WebRTC 探测局域网 IP。
- 特效模块独立：`effects/particles.js`（粒子池 + 各发射器）、`effects/camera.js`（trauma 震屏）、`audio/sfx.js`（Web Audio 合成）；主循环通过回调挂钩（砖块销毁、拾取、命中）触发。

## 目录结构

```text
index.html          入口页面、三选一卡片与结算覆盖层
server.mjs          零依赖静态服务器（npm start）
src/
  main.js           状态机（playing/upgrading/gameover）与战斗结算
  config.js         全局常量与玩家基础属性
  core/
    gameLoop.js     固定时间步主循环
    input.js        键盘 + 鼠标输入
    bulletPool.js   子弹对象池
  entities/
    directions.js   四方向辅助
    tank.js         玩家坦克（属性面板 + applyUpgrade）
    bullet.js       子弹（携带升级快照）
    enemy.js        敌人（冰冻减速 / 燃烧灼烧）
    boss.js         Boss（弹幕 / 召唤 / 冲锋）
    pickup.js       经验宝石
    item.js         道具（急救 / 护盾 / 清屏 / 狂暴）
  world/
    map.js          瓦片地图与随机生成
    wave.js         波次管理（isCleared / advance）
    upgrades.js     13 种升级定义与随机抽取
  effects/
    particles.js    像素粒子系统与发射器
    camera.js       屏幕震动
  audio/
    sfx.js          Web Audio 8-bit 音效合成
  render/
    arena.js / map.js / tileSprites.js / tank.js / pickup.js / hud.js
```
